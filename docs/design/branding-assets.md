# Showcase branding assets

The CWRU Spartan artwork in `demo/assets/cwru-spartan.svg` was downloaded unchanged from the CWRU Athletics website's header asset:
https://dxbhsrqyrr690.cloudfront.net/sidearm.nextgen.sites/casewestern.sidearmsports.com/images/responsive_2023/logo-main.svg

Brand reference: https://case.edu/brand/visual-identity/logos/athletics-logo

The user requested this mark for the local Research Connect showcase. No institutional approval or public deployment was established by this change.

The showcase uses authored fictional fixtures. Removing explanatory copy from the interface does not make the listings live or implement applications or messaging.

Design method: Unslop by Damir Sokolovsky (@heydamir), CC BY 4.0.
https://github.com/heydamir/unslop
