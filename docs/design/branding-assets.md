# Showcase branding assets

The CWRU Spartan artwork in `demo/assets/cwru-spartan.svg` was downloaded unchanged from the CWRU Athletics website's header asset:
https://dxbhsrqyrr690.cloudfront.net/sidearm.nextgen.sites/casewestern.sidearmsports.com/images/responsive_2023/logo-main.svg

Brand reference: https://case.edu/brand/visual-identity/logos/athletics-logo

The user requested this mark for the local Research Connect showcase. No institutional approval or public deployment was established by this change.

The showcase uses authored fictional fixtures. Removing explanatory copy from the interface does not make the listings live or implement applications or messaging.

Design method: Unslop by Damir Sokolovsky (@heydamir), CC BY 4.0.
https://github.com/heydamir/unslop

## Profile portrait

The generic showcase avatar in demo/assets/profile-avatar.jpg comes from Random User Generator:
https://randomuser.me/api/portraits/men/75.jpg

Source documentation: https://randomuser.me/
The source describes these as UI placeholder photos. The portrait is illustrative and does not identify the fictional profile owner.

## Landing hero photograph

The laboratory photograph in demo/assets/hero-lab.jpg ("Scientist using laptop in laboratory") is by ThisisEngineering on Unsplash, used under the Unsplash License (free to use, attribution appreciated):
https://unsplash.com/photos/scientist-using-laptop-in-laboratory-8yS04veb1TQ

It is a stock image and does not depict a CWRU lab or person. The landing page darkens it with a navy gradient so the headline and search stay readable.
